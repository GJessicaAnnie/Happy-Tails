Happy Tails – Pet Adoption System

Happy Tails is a MERN-based pet adoption platform designed to simplify the pet adoption process by connecting potential adopters with animal shelters. The system allows users to browse available pets, search and filter pets, view pet details, submit adoption requests, track application status, and book appointments.
Features:
* User registration and login
* Browse available pets
* Search and filter pets
* Detailed pet profiles
* Online adoption applications
* Adoption request tracking
* Appointment booking
* Admin dashboard
* Pet and user management
* Adoption and appointment request management

Technologies Used:
* React.js
* Node.js
* Express.js
* MongoDB
* REST APIs
* JavaScript
* HTML
* CSS
* Git and GitHub
* Jira for testing and issue tracking

Project Objective:
The objective of Happy Tails is to provide a centralized, efficient, and transparent platform for pet adoption while reducing the limitations of traditional manual adoption processes and promoting responsible pet ownership.
